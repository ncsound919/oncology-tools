How it works

  1. Tune Ingestion controls (sources, page size, dedup, date window).
  2. Launch a study — one commander fans it to every matching system (4-at-a-time, fail-soft).
  3. Report lands in data/reports/ as .json + .md.
  4. Add a cron for recurring work (e.g. 0 * * * * hourly).
  5. Bring offline systems online — next report widens automatically.
